EyeType

october 2025 — present
figmareactai

EyeType is a web-based augmentative and alternative communication software built for individuals with severe motor impairments including ALS, cerebral palsy, and muscular dystrophy. It uses eye tracking and a fine-tuned LLM to significantly outperform baselines and make communication easier for those with motor impairments. The user simply types the first letter of each word, and the software automatically predicts complete phrases based on the context of the conversation. It is completely free and requires no external hardware.
